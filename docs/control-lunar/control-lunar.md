# Control lunar Pontix - procedura si fise de verificare

Editia 1.0 - 31 octombrie 2026. F02-T23. Procedura propusa, de adaptat si aprobat de organizatie.

Procedura propusa pentru operator si responsabilul de pontaj. Nu introduce reguli de salarizare, praguri sau blocari automate si nu inlocuieste validarile contabilitatii. Nu toate verificarile sunt automatizate in aplicatie.

T = trecut; N = neconform; A = neaplicabil. O casuta nemarcata inseamna neexecutat. Pentru N se noteaza problema, responsabilul si termenul; pentru A se explica motivul. Nu se deduc deficitul contractual, orele suplimentare sau sporurile din diferenta dintre coloane. Inchiderea lunii nu calculeaza si nu plateste automat salariile.

Completati perioada, operatorul, rezultatul si observatiile. Pastrati fisa conform procedurii organizatiei; nu consemnati parole, chei sau date personale inutile.
