# D062 - Structura profesionala si contracte configurabile

Stare: propusa. Propusa de Codex, 2026-10-31. Task F07-T25.

Se separa grupul profesional, functia (cu pozitia conducere/executie), contractul si asocierea marcii de garda. Ordinea numerica a grupului si a functiei sunt configurabile; sefii sunt primii, restul alfabetic romanesc. Marcile asociate raman impreuna, cu incadrarea principala in raport.

Nomenclatoarele au ID stabil, denumiri RO/EN, revizie, activ/dezactivat si audit. Datele istorice nu sunt reclasificate automat. Contractele configurabile se asociaza separat pentru compatibilitate cu coloanele istorice; fara norma inseamna lipsa normei, nu zero ore lucrate. Filtrul garda se refera la marca/contract, nu la existenta unei ture intr-o luna. Fara biblioteci noi. Reguli contabile neprecizate sunt consemnate la F01.
