# D064 - Legenda coloanelor raportului

Stare: acceptată. Codex, 2026-10-31. Task F09-T12 · Decisă de: Ioan Tuns, 2026-11-06 (F02-T25)

Ore norma este ascunsa din raportul detaliat, fara schimbarea motorului sau a grilei. Legenda este construita din coloanele vizibile, semnificatii traduse si formulele efectiv configurate, inclusiv factor, coduri, aprobari si reguli conditionate. Zilele calendaristice sunt explicate o singura data. Formula nedefinita este marcata explicit; solicitarile inca neintegrate nu sunt descrise ca reguli active.

Legenda este repetata in subsolul PDF si inclusa dupa date in Excel-ul aceluiasi document. Se pastreaza semnaturile, imaginile si metadatele existente. Rapoartele se versioneaza si se pastreaza referintele vechi. Fara biblioteci noi.
