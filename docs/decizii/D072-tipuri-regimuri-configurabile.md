# D072 - Tipuri si regimuri de program configurabile

Stare: acceptată. Codex, 2026-10-31. F07-T35 · Decisă de: Ioan Tuns, 2026-11-06 (F02-T25)

Utilizatorul solicita eliminarea General/anterior si configurarea tipurilor/regimurilor, cu pastrarea legaturilor. General se migreaza la regimul normal LUCRATOARE; tipul NORMAL/TURA/NOAPTE/GARDA este independent si se pastreaza.

Nomenclatoare editabile cu identitate stabila si comportament explicit. Nume si activare editabile; pentru un comportament nou se poate crea o definitie noua. Schimbarea comportamentului unei definitii deja utilizate este refuzata, evitand reclasificarea retroactiva a programelor si rapoartelor. Programele salveaza referinte la definitii si comportamentul efectiv, pastrand integrarea motorului existent. Categoriile si contractele continua sa refere aceleasi programe, nu copii. Dezactivarea opreste asignari noi, fara stergerea istoricului. Fara procente sau reguli de plata noi.
