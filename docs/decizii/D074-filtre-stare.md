# D074 - Filtrare unitara a starii

Stare: acceptată. Codex, 2026-10-31. F16-T27 · Decisă de: Ioan Tuns, 2026-11-06 (F02-T25)

Utilizatorul solicita filtre active/inactive in toate meniurile, implicit active. Se foloseste componenta comuna cu Active/Inactive/Toate si stare locala per lista. Angajati pastreaza selectorul existent, implicit activi. Se acopera toate listele de administrare cu camp activ, inclusiv regulile conditionate, angajatii Pontaj/Planificare si pozitiile planificate.

Filtrarea este vizuala, fara stergeri sau recalculare a istoricului. Formularele pastreaza referintele inactive deja selectate. Pozitiile inactive ale planificarii au sens numai in lista; grila continua sa reprezinte pozitiile active. Calendarul, jurnalul si backupurile nu au camp activ si nu primesc stari artificiale. Generarea rapoartelor pastreaza regulile existente si modelele active; istoricul nu este exclus implicit din rapoartele contabile. Regula noua initial inactiva este facuta vizibila prin trecere la Toate. Nicio regula de plata schimbata.
