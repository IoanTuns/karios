# Pornire si actualizare Pontix {{VERSIUNE}}

Build: {{COMMIT}}. Pachet Windows x64 portabil. Aplicatia foloseste Microsoft Edge WebView2 Runtime; pe un calculator curat verificati disponibilitatea lui. AI generativ necesita separat un motor si un model compatibil; ghidurile locale nu necesita model.

Prima pornire: extrageti intreaga arhiva intr-un folder in care aveti drept de scriere, apoi porniti executabilul si creati administratorul. Pastrati cheia de recuperare separat. Nu rulati direct din arhiva ZIP.

Actualizare:
1. Creati un backup din Setari si verificati mesajul cu locatia.
2. Inchideti complet aplicatia si pastrati o copie completa a folderului vechi.
3. Extrageti pachetul nou intr-un folder separat.
4. Copiati intregul folder karios vechi langa noul executabil; nu doar baza de date. Nu amestecati date demo cu date reale.
5. Porniti noua aplicatie si parcurgeti eventuala deblocare.
6. Verificati angajatii, pontajul, planificarea si rapoartele inainte de folosire.

Daca apare o problema, inchideti aplicatia si pastrati ambele copii. Nu inlocuiti doar executabilul vechi peste o baza deja migrata: revenirea se face pe copia completa pastrata inainte de actualizare. Contactati responsabilul aplicatiei cu versiunea si pasii de reproducere, fara date personale.

Consultati manualul HTML/PDF inclus. Checklistul de acceptanta se executa pe date fictive, intr-un director separat de datele reale.
